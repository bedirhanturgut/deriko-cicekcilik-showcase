# Public Repository Security Boundary

The raw production package must **not** be uploaded to a public repository.

Excluded from this showcase:

- `admin/storage/data.json`
- `site-admin/storage/site.json`
- user names and e-mail addresses
- password hashes
- customer records
- supplier records
- sales and accounting history
- customer ledger entries
- uploaded production assets when ownership/privacy is unclear
- production APK / deployment files

Only sanitized examples and approved screenshots belong in this repository.
